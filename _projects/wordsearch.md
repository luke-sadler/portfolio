I created this as a learning experience. I don't have much recent experience with creating libraries so I decided to create a small project to bring me back up to speed.  
This library can be imported via SPM, is covered by unit tests, has a sample/ demo project, and has some documentation. 
As this is just a for-fun/ learning experience, I didn't go overboard with functionality, but I believe my first iteration has enough to get a simple game off the ground.
